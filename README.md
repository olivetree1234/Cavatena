The purpose of Cavatena is to help violin students organize their practice sessions, manage their repertoire, track their progress, and encourage discipline and consistency in those sessions. 
Cavatena allows users to create practice plans and select exercises and pieces from a music library. 
The library includes scales, techniques, etudes, solo pieces, and orchestral music. Users can also import their own music lists using CSV files. 
My goal is to make violin practice grounded by providing a convenient tool that manages all activities in one place.
